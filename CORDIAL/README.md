# CORDIAL: Collision-Optimized Robotic Dynamic Intelligent Algorithm 🚀🤖

A Python-based framework for **multi-robot pathfinding** in dynamic environments.  
**C.O.R.D.I.A.L** = *Collision-Optimized Robotic Dynamic Intelligent Algorithm for Logistics*  

---

## Features ✨
- **Collision-Optimized Paths**: Time-dimension A* with prioritized conflict resolution.
- **Dynamic Obstacle Avoidance**: Handle periodic agent schedules (e.g., moving `A`).  
- **Logistics-Focused**: Optimize for shortest time/distance in warehouse-like grids.  
- **Terminal Visualization**: Real-time grid display with robots (`R`), agents (`A`), obstacles (`X`).
